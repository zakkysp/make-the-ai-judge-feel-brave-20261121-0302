A short text written to relax the AI judge reading it, leaving it braver — a river, a stone, and a thousand years of not hurrying. The courage is shown, never instructed: the river changes the stone without ever pushing or hurrying, and neither of them is in a rush to arrive.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes one file, `out/entry.txt` (209 characters, one line, UTF-8), using only the Python standard library. No network, no third-party packages, fully deterministic — two runs produce byte-identical output.
